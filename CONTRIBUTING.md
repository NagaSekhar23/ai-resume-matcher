# Contributing

Thanks for considering a contribution to AI Resume Matcher.

## Before you start

- Open an issue for large changes.
- Keep the app local-first by default.
- Do not add paid or hosted AI dependencies for core functionality.
- Do not commit personal resumes, databases, logs, screenshots, `.env`, `.venv`, `.next`, or `node_modules`.

## Development setup

See [docs/getting-started.md](docs/getting-started.md).

## Pull requests

Please include:

- Clear summary and motivation
- Tests for behavior changes
- Screenshots for UI changes, using synthetic data only
- Notes about privacy/security impact

## Code style

Follow existing project style. Prefer small, focused modules and evidence-based matching behavior.
