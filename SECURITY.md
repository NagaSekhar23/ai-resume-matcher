# Security Policy

## Reporting a vulnerability

Please report security issues privately by opening a GitHub security advisory on the repository when available, or by contacting the maintainer through GitHub: `NagaSekhar23`.

Please include:

- A clear description of the issue
- Steps to reproduce
- Affected files or endpoints
- Potential impact
- Suggested fix if known

Do not publish exploit details publicly until the issue has been reviewed.

## Scope

Security-sensitive areas include upload validation, local file storage, path handling, unsafe rendering of resume text, local database access, launcher scripts, and LLM prompt/data handling.

## Privacy expectations

Never include real resumes, logs, databases, extracted text, credentials, or screenshots with personal information in a public issue.
