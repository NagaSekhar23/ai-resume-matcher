# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good intent.
- Keep feedback focused on ideas and implementation.
- Respect privacy; never request or publish personal resume data.

## Unacceptable behavior

Harassment, abusive language, discrimination, doxxing, or publishing private user data is not acceptable.

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributors that violate this code of conduct.
